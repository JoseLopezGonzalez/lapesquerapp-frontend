# Bandeja de entrada — Assets de logo

Mete aquí los archivos que vayas creando desde Illustrator con el nombre que quieras.
Cuando estén listos, dile a Claude que los mueva y los reubicará automáticamente al destino correcto.

---

## Destino de cada archivo según nombre

| Si el archivo se llama (o se parece a)... | Lo muevo a... |
|---|---|
| `logo-horizontal.*` / `navbar.*` / `blueapp-logo*` | `public/logos/blueapp-logo-horizontal.png` |
| `icon-512*` / `icono-512*` | `public/pesquerapp/icons/icon-512x512.png` |
| `icon-192*` / `icono-192*` | `public/pesquerapp/icons/icon-192x192.png` |
| `apple-touch*` / `ios-icon*` / `touch-icon*` | `public/pesquerapp/apple-touch-icon.png` |
| `favicon-96*` / `fav-96*` | `public/pesquerapp/favicon-96x96.png` |
| `favicon.svg` | `public/pesquerapp/favicon.svg` |
| `favicon.ico` | `public/pesquerapp/favicon.ico` |
| `og-image*` / `og*` / `social*` | `public/pesquerapp/og-image.png` |
| `brisamar*` / `tenant*` | `public/images/tenants/logos/brisamar.png` |
| `splash-*` / `iphone-*` / `ipad-*` | `public/pesquerapp/splash/{nombre}.png` |

No te preocupes por el nombre exacto — dime qué es cada archivo y yo lo coloco.
