# GAP-V2-074 — Uso inconsistente de `style={{}}` en la vista de palet

## Problema

`design-context.md` § What NOT To Do prohíbe `style={{}}` inline en componentes nuevos o
modificados. El módulo Pallets tiene varios usos, con distinto nivel de justificación:

1. **Inconsistente con un patrón ya establecido en el mismo módulo** —
   `AddManualScreen.tsx:164`:

   ```tsx
   style={{ paddingBottom: 'calc(1rem + env(safe-area-inset-bottom))' }}
   ```

   El propio `MobilePalletView/index.tsx:382` resuelve el mismo problema (safe-area en la
   barra sticky de guardar/descartar) con la sintaxis de valor arbitrario de Tailwind, sin
   `style={{}}`:

   ```tsx
   className = '... pb-[calc(0.75rem+env(safe-area-inset-bottom))] ...';
   ```

   `AddManualScreen.tsx` debería seguir el mismo patrón ya usado a pocos archivos de
   distancia en vez de introducir una segunda forma de resolver el mismo problema.

2. **Fácilmente convertible a valor arbitrario de Tailwind** —
   `PalletImagesTab/index.tsx:345`: `style={{ scrollbarWidth: 'none' }}` en el contenedor
   de miniaturas del lightbox — no tiene equivalente de utilidad Tailwind directa, pero
   puede resolverse con una clase de utilidad local (`scrollbar-none` ya podría existir o
   añadirse una vez a `globals.css` como excepción documentada, en vez de repetir `style`
   en cada sitio que lo necesite).

3. **Dimensiones dinámicas que dependen de config runtime** —
   `PalletView/index.tsx:2450,2456-2459` y `PalletLabelDialog/index.tsx:63,67,127,149`:
   usan `style={{ width: PALLET_LABEL_SIZE.width, height: PALLET_LABEL_SIZE.height }}` y
   `style={{ maxWidth: ... })` para el tamaño físico de la etiqueta de impresión — un valor
   que viene de `configs/config.js` y no es conocido en build time. Este caso es el más
   defendible de los cuatro (no hay forma de expresar un valor de configuración runtime
   como clase Tailwind estática), pero no está documentado como excepción en
   `design-context.md`, a diferencia de los inline colors de status badges.

## Objetivo

Reducir el uso de `style={{}}` en el módulo Pallets al mínimo estrictamente necesario
(dimensiones dinámicas de configuración runtime para impresión de etiquetas), unificando
el resto bajo el patrón Tailwind ya usado en el propio módulo, y documentar en
`design-context.md` la excepción de `PALLET_LABEL_SIZE` como caso legítimo (igual que ya
existe la excepción de status badge colors).

## Contexto

No es un blocker de funcionalidad — es una inconsistencia de patrón dentro del mismo
módulo que aumenta el coste de mantenimiento (dos formas de resolver el mismo problema de
safe-area en archivos hermanos).

## Solución propuesta

- `AddManualScreen.tsx`: reemplazar `style={{ paddingBottom: ... }}` por
  `pb-[calc(1rem+env(safe-area-inset-bottom))]` en el `className`, igual que
  `MobilePalletView/index.tsx`.
- `PalletImagesTab/index.tsx`: evaluar sustituir `style={{ scrollbarWidth: 'none' }}` por
  una utilidad Tailwind reutilizable (o mantenerlo si no existe alternativa, pero
  documentarlo en `design-context.md` como excepción puntual).
- `PalletView/index.tsx` y `PalletLabelDialog/index.tsx`: mantener el uso de
  `PALLET_LABEL_SIZE` vía `style={{}}` (es el caso legítimo, valor de config runtime) pero
  añadir una nota en `design-context.md` § What NOT To Do documentando esta excepción,
  igual que ya existe para status badge colors — para que futuras auditorías no lo
  reporten como falso positivo.

## Criterios de aceptación

- [ ] `AddManualScreen.tsx` ya no usa `style={{}}` para el padding de safe-area — usa la
      sintaxis de valor arbitrario de Tailwind.
- [ ] `PalletImagesTab/index.tsx` documenta o sustituye el uso de `scrollbarWidth` inline.
- [ ] `design-context.md` incluye una entrada de excepción para `PALLET_LABEL_SIZE`
      (dimensiones de etiqueta de impresión dependientes de configuración runtime).
- [ ] No se modifica el tamaño visual resultante de ningún elemento — el cambio es
      exclusivamente de forma de expresión (style vs className).
