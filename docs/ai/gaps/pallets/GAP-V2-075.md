# GAP-V2-075 — `InfoTab.tsx` (MobilePalletView) es un componente huérfano no usado

## Problema

`src/components/Admin/Pallets/PalletDialog/MobilePalletView/InfoTab.tsx` implementa un
formulario combinado de tara + observaciones + pedido vinculado, pero no se importa desde
ningún sitio del proyecto:

```text
$ grep -rn "InfoTab" src/
src/components/Admin/Pallets/PalletDialog/MobilePalletView/InfoTab.tsx:24:interface InfoTabProps {
src/components/Admin/Pallets/PalletDialog/MobilePalletView/InfoTab.tsx:36:export default function InfoTab({
src/components/Admin/Pallets/PalletDialog/MobilePalletView/InfoTab.tsx:46:}: InfoTabProps) {
```

El flujo mobile real implementa estos tres campos como pantallas separadas
(`TaraScreen.tsx`, `ObservacionesScreen.tsx`, `PedidoScreen.tsx`), cada una navegable desde
`HubScreen.tsx` y enrutada en `MobilePalletView/index.tsx`. `InfoTab.tsx` parece ser una
versión anterior (combinada en una sola pantalla) que quedó sin eliminar tras el rediseño a
pantallas independientes.

Este tipo de componente huérfano es un riesgo concreto de UX/consistencia: si alguien edita
`InfoTab.tsx` pensando que es la pantalla en producción (comparte tipos y lógica muy
similar a las tres pantallas activas), el cambio no tendría ningún efecto visible y
generaría una divergencia silenciosa entre lo que el código "parece hacer" y lo que
realmente se renderiza.

## Objetivo

No existe código muerto en `MobilePalletView` que pueda confundirse con una pantalla activa
del flujo de edición de palet.

## Contexto

Descubierto durante la lectura completa de `MobilePalletView/*.tsx` para esta auditoría.
Confirmado con grep en todo `src/` que no hay ningún import de `InfoTab`.

## Solución propuesta

Eliminar `InfoTab.tsx` si se confirma que las tres pantallas separadas (`TaraScreen`,
`ObservacionesScreen`, `PedidoScreen`) son la versión vigente y no hay planes de volver al
formulario combinado. Si existiera un plan de reintroducirlo, mover el archivo fuera de
`MobilePalletView/` (p.ej. a una carpeta `_archived/` o similar) con una nota explícita, en
vez de dejarlo activo junto a los componentes en producción.

## Criterios de aceptación

- [ ] `InfoTab.tsx` se elimina del directorio `MobilePalletView/`, o se documenta
      explícitamente por qué se mantiene sin uso.
- [ ] `grep -rn "InfoTab" src/` no devuelve resultados tras la limpieza (salvo que se decida
      mantenerlo documentado).
- [ ] No se afecta ningún import real de `TaraScreen`, `ObservacionesScreen` o
      `PedidoScreen`.

