# GAP-V2-104 — Falta columna "Posición" en el listado de palets

## Problema

El filtro `position` (`src/configs/entities/entitiesConfig.stock.ts:483-491`) permite
filtrar palets por "Ubicado" / "No ubicado", pero la tabla resultante (`table.headers`,
líneas 577-636) no muestra en ningún punto el código de posición física dentro del almacén
(el mismo campo `pallet.position` que sí se usa y muestra en
`AddElementToPositionDialog/index.tsx:311-316` como badge `<MapPin/>{pallet.position}`).

Para un operario que filtra "palets ubicados" de un almacén con el objetivo de ir a
recogerlos físicamente, el dato que necesita ver en la lista es precisamente *dónde* está
cada uno (p.ej. "A1-B2"), no solo que "está ubicado". Hoy, tras filtrar, tiene que abrir
cada palet uno a uno (o ir al mapa del almacén en `StoresManager`) para averiguar su
posición exacta — el listado, que es la superficie pensada para localizar palets por
criterio, no resuelve la pregunta más básica de "¿en qué posición está?".

## Objetivo

La tabla de palets muestra una columna "Posición" con el código de ubicación física
(vacío/"–" cuando el palet no está ubicado), consistente con el dato ya usado en el módulo
de almacenes.

## Contexto

Detectado en la auditoría de dominio de la Superficie A (listado de palets) de la segunda
pasada v2 de `pallets`. Complementa (no depende de) GAP-V2-103.

## Solución propuesta

Añadir un header `{ name: 'position', label: 'Posición', type: 'text', path: 'position' }`
(o el tipo que corresponda si el backend expone el nombre de posición además del id) junto
a la columna `store` ya existente, para que ambas —almacén + posición— den la localización
completa del palet en una sola fila.

## Criterios de aceptación

- [ ] La tabla de palets muestra una columna "Posición" junto a la columna "Almacén".
- [ ] Palets sin posición asignada muestran el placeholder estándar ("–") en vez de vacío.
- [ ] El filtro "Ubicado/No ubicado" existente sigue funcionando sin cambios.

## Plan de validación

```text
npm run type-check
npm run lint
Verificación manual: filtrar por "Ubicado" en /admin/pallets y confirmar que la posición
física es visible directamente en la tabla sin abrir cada registro.
```
