# GAP-V2-105 — Sin atajo de filtro para "stock disponible" en el listado de palets

## Problema

El listado de palets ya calcula y muestra `availableBoxesCount`/`usedBoxesCount` y
`totalAvailableWeight`/`totalUsedWeight` como columnas
(`src/configs/entities/entitiesConfig.stock.ts:608-635`), pero no existe ningún filtro que
permita acotar la búsqueda a "palets con stock disponible" o "palets agotados/comprometidos
por completo". Los filtros existentes (estado, posición, fechas, productos, especies,
almacenes, pedidos) permiten localizar palets por criterios de identidad, pero no por
disponibilidad real de stock.

En la operativa diaria de una pesquera/congelados, la pregunta más frecuente al preparar un
pedido o revisar existencias es "¿qué palets tengo con stock disponible del producto X?" —
hoy, tras filtrar por producto o especie, el usuario tiene que recorrer visualmente todos
los resultados y comparar `availableBoxesCount` columna a columna para descartar los que ya
están completamente consumidos (en producción) o sin stock disponible. No hay atajo para la
operación que, según el propio diseño de columnas del listado, el sistema ya sabe responder.

## Objetivo

El listado de palets permite filtrar por disponibilidad de stock (p.ej. "Con stock
disponible" / "Agotado"), reduciendo el recorrido manual de columnas para la operación más
frecuente de localizar stock disponible de un producto/especie.

## Contexto

Detectado en la auditoría de dominio de la Superficie A (listado de palets) de la segunda
pasada v2 de `pallets`. Relacionado conceptualmente con `getAvailableBoxesCount` /
`getAvailableNetWeight` (`src/helpers/pallet/boxAvailability.js`), ya usados para las
columnas existentes.

## Solución propuesta

Añadir un filtro tipo `pairSelectBoxes` (mismo patrón que `state` o `position`) con opciones
"Con stock disponible" / "Agotado", mapeado en el backend a `availableBoxesCount > 0` /
`availableBoxesCount = 0` (o el criterio equivalente que use el endpoint de listado).
Confirmar con Jose si el backend ya soporta este filtro o requiere un cambio de API antes de
implementar el lado frontend.

## Criterios de aceptación

- [ ] Existe un filtro de disponibilidad de stock en el grupo "Generales" del listado de
      palets.
- [ ] Filtrar por "Con stock disponible" excluye palets con `availableBoxesCount = 0`.
- [ ] El filtro combina correctamente con producto/especie/almacén ya existentes.

## Plan de validación

```text
npm run type-check
npm run lint
Verificación manual: combinar el nuevo filtro con producto/especie y confirmar que reduce
la lista a solo los palets con stock disponible de ese producto.
```
