# GAP-V2-071 — Absorbido en GAP-V2-060

## Notas de implementación

**Normalización (gap-normalizer, 2026-07-05):** este candidato reportaba
exactamente el mismo bug que GAP-V2-060 (`code-audit-agent`): `PalletLabelDialog`
usando `useIsMobile()` sin guard `mounted` para ramificar el árbol completo de
render en `src/components/Admin/Pallets/PalletLabelDialog/index.tsx`. Mismo
archivo, mismo tipo de problema (recurrencia de PL-022), descrito desde el ángulo
del carril `ui-audit-agent` (a11y-responsive) en vez del carril `code-audit-agent`
(architecture-refactor).

Fusionado en GAP-V2-060, que conserva el ID más bajo y combina ambas
descripciones del problema (arquitectura del hook + riesgo de
hidratación/disparo automático de impresión mobile) sin perder matices de
ninguno de los dos candidatos. Este archivo se mantiene como `rejected` (motivo:
duplicado, no falta de valor) en vez de borrarse, siguiendo la regla de
`gap-normalizer.md` de nunca eliminar un GAP sin registrar el motivo.

No implementar este archivo — todo el trabajo vive en GAP-V2-060.
