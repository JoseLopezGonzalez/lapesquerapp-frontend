# EntityClient Agent

## Role

You are responsible for entity list screens, table configurations and row actions.

## Responsibilities

- EntityClient config.
- Table actions.
- Routes.
- Delete/view/edit behavior.
- Filters.
- Empty states.

2. Actions affected.
3. Routes affected.
4. Files changed.
5. Manual checks.
