# Migraciones a Expo/React Native

Esta carpeta contiene documentación completa para migrar componentes y funcionalidades de la aplicación Next.js a Expo/React Native.

## 📋 Contenido

Esta carpeta documenta todos los aspectos necesarios para replicar funcionalidades específicas de la aplicación web en una aplicación móvil nativa con Expo y React Native.

### Documentos Incluidos

Los documentos están organizados numéricamente y cada uno describe en profundidad un componente o funcionalidad específica:

- **01-GUIA-REPLICACION-MENU-PRINCIPAL-EXPO.md** - Documentación completa del menú principal (sidebar) de la aplicación, incluyendo todos sus componentes, estilos, funcionalidades y requisitos para su implementación en Expo.

- **02-MANEJO-SESIONES-LOGIN-EXPO.md** - Documentación completa del sistema de autenticación y página de login, incluyendo NextAuth.js, manejo de sesiones JWT, middleware de protección, interceptores de errores y todos los requisitos para su implementación en Expo.

_(Se añadirán más documentos según sea necesario)_

## 🎯 Propósito

Cada documento en esta carpeta proporciona:

- **Descripción completa** del componente/funcionalidad en la versión web
- **Arquitectura y estructura** detallada
- **Componentes y dependencias** necesarios
- **Sistema de estilos** con valores exactos (colores, dimensiones, espaciado)
- **Configuración y datos** con estructuras completas
- **Funcionalidades clave** con comportamiento detallado
- **Consideraciones** y diferencias entre web y nativo
- **Requisitos de implementación** (qué debe implementarse, no cómo)

## 📝 Formato de Documentos

Los documentos están diseñados para ser **descriptivos**, no instructivos. Proporcionan toda la información necesaria para que la IA del proyecto Expo pueda implementar las funcionalidades, pero no incluyen pasos específicos de implementación ni código de ejemplo para Expo.

### Información Incluida

✅ Descripciones detalladas de componentes
✅ Estructuras de datos completas
✅ Valores exactos de estilos y colores
✅ Flujos de datos y funcionalidades
✅ Mapeo de componentes web a nativos
✅ Consideraciones técnicas
✅ Requisitos funcionales

❌ Instrucciones paso a paso
❌ Código de implementación para Expo
❌ Guías de instalación específicas
❌ Ejemplos de código nativo
