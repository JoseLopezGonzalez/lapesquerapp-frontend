# Identidad visual — La Pesquerapp

Documento base para conservar la dirección visual del logo, futuras versiones, evoluciones y decisiones de marca de **La Pesquerapp**.

Última actualización: 2026-06-24
Estado: Borrador inicial de identidad visual
Ruta elegida: **Ruta A — Ondas refinadas**

---

# 1. Nombre de marca

## Nombre principal

**La Pesquerapp**

> **Pendiente de alinear:** `src/configs/branding.ts` actualmente define el nombre como `La PesquerApp` (P mayúscula). Si la decisión de marca es usar la minúscula (`La Pesquerapp`), actualizar el campo `appName` en ese archivo para que sea la fuente de verdad.

## Uso recomendado

Usar siempre:

```txt
La Pesquerapp
```

Evitar como nombre principal:

```txt
PESQUERAPP
La Pesquerapp ERP
La Pesquera App
```

Aunque internamente el producto sea un ERP, la marca debe sentirse como una **app SaaS moderna**, no como un software empresarial antiguo o excesivamente técnico.

---

# 2. Concepto general

La identidad visual de **La Pesquerapp** debe representar una aplicación moderna, limpia y cercana para la gestión del sector pesquero.

La marca debe transmitir:

* Software moderno.
* Simplicidad.
* Flujo.
* Orden.
* Mar.
* Gestión.
* Producto digital.
* Cercanía.
* Profesionalidad sin rigidez.
* Estética compatible con interfaces minimalistas tipo shadcn/ui.

La marca no debe parecer una pescadería, una conservera, una empresa tradicional del sector pesquero ni una marca alimentaria clásica. Debe parecer una herramienta digital actual para empresas del sector.

# 3. Dirección visual elegida

## Ruta seleccionada

**Ruta A — Ondas refinadas**

La dirección elegida parte del logo original, que usaba ondas como referencia al mar, pero se refinan sus formas para hacerlo más:

* Minimalista.
* Profesional.
* Abstracto.
* Escalable.
* Compatible con icono de app.
* Compatible con favicon.
* Coherente con una UI en blanco y negro.

## Idea central

El símbolo se basa en **tres ondas horizontales refinadas**, dibujadas con trazo redondeado, peso visual equilibrado y forma muy simple.

Las ondas pueden leerse como:

* Agua / mar.
* Flujo de trabajo.
* Movimiento de producto.
* Procesos.
* Datos.
* Continuidad.
* Sistema.

La lectura principal debe ser simple y abstracta. No debe ser una ilustración literal del mar.

# 5. Símbolo principal

## Descripción

El símbolo principal está compuesto por tres ondas simples, negras o blancas según el fondo, dentro de una caja redondeada.

La onda debe tener:

* Trazo grueso o medio-grueso.
* Extremos redondeados.
* Curvas suaves.
* Buena separación entre líneas.
* Buena legibilidad en tamaños pequeños.
* Apariencia equilibrada y compacta.

## Características formales

* Estilo: minimalista.
* Forma: abstracta.
* Trazos: redondeados.
* Peso: medio/grueso.
* Número de ondas: preferiblemente 3.
* Caja contenedora: cuadrado redondeado.
* Detalle: mínimo.
* Color principal: blanco y negro.

## Criterio de diseño

El símbolo debe funcionar incluso si el usuario no sabe que es una app del sector pesquero. Debe sentirse como una marca de software moderna, con una relación sutil con el mar.

# 6. Caja / contenedor del icono

## Uso

La caja redondeada forma parte importante de la identidad visual, especialmente para:

* Icono de app.
* PWA.
* Favicon.
* Sidebar.
* Dashboard.
* Pantalla de carga.
* Tarjetas de marca.
* Versión compacta del logo.

## Forma recomendada

* Cuadrado con esquinas redondeadas.
* Radio amplio, estilo app icon.
* Sin borde en la versión negativa.
* Borde sutil en la versión positiva sobre fondo claro.

## Sensación buscada

La caja debe sentirse como un icono de producto digital, no como una chapa, sello o etiqueta industrial.

Para una presencia algo más amable y cercana, explorar:


## Estilo tipográfico

La tipografía debe ser:

* Limpia.
* Moderna.
* Redondeada sin ser infantil.
* Técnica sin ser fría.
* Muy legible.
* Compatible con UI.

Evitar:

* Serif clásicas.
* Tipografías manuscritas.
* Fuentes demasiado futuristas.
* Fuentes industriales agresivas.
* Tipografías decorativas.

# 13. Usos sobre fondos

## Fondo claro

Usar preferentemente:

```txt
Icono negro + ondas blancas
```

O:

```txt
Icono blanco + ondas negras + borde sutil
```

## Fondo oscuro

Usar preferentemente:

```txt
Icono blanco + ondas negras
```

O:

```txt
Icono negro + ondas blancas si hay suficiente contraste
```

## Fondo fotográfico

Usar el icono dentro de caja sólida para asegurar legibilidad.

Evitar colocar las ondas solas sobre fotografía si no hay contraste suficiente.

---

# 14. Área de respeto

El logo debe tener un margen mínimo alrededor.

## Regla recomendada

El área mínima de respeto debe ser equivalente a la altura aproximada de una onda del símbolo.

Ningún texto, borde, botón o elemento visual debe invadir ese espacio.

---

# 16. Reglas de uso

## Correcto

* Usar el símbolo en blanco y negro.
* Mantener las ondas limpias.
* Mantener buena separación interna.
* Usar caja redondeada.
* Respetar el área de seguridad.
* Usar el logo en entornos minimalistas.
* Mantener contraste suficiente.
* Usar versiones monocromas.

## Incorrecto

* Añadir pez, anzuelo, barco, pulpo o caja.
* Añadir degradados innecesarios.
* Usar sombras fuertes.
* Deformar el icono.
* Estirar las ondas.
* Cambiar el grosor de una sola onda.
* Usar colores muy saturados sin motivo.
* Poner el logo sobre fondos con poco contraste.
* Añadir demasiados detalles.
* Convertirlo en una ilustración.
* Usar tipografías decorativas.
* Cargar el logo con texto adicional.

# 21. Variantes futuras posibles

Puede existir una versión secundaria azul, pero no debe sustituir a la principal salvo decisión futura.

## Variante solo símbolo

Puede usarse para favicons, app icons y espacios muy reducidos.

Podría explorarse en el futuro, pero actualmente la caja redondeada forma parte importante de la identidad.

## Variante animada

Posible para splash screen o loading:

* Ondas entrando suavemente.
* Ondas con movimiento mínimo.
* Transición sutil de opacidad.
* Microanimación tipo flujo.

# 22. Criterios para futuras actualizaciones

Cualquier evolución del logo debe respetar:

* Simplicidad extrema.
* Caja redondeada.
* Ondas como base semántica.
* Trazos redondeados.
* Compatibilidad blanco/negro.
* Legibilidad en icono pequeño.
* Estética SaaS moderna.
* No literalidad pesquera.
* Coherencia con shadcn/ui.

## Pregunta clave antes de cambiar el logo

Antes de modificar el logo, comprobar:

```txt
¿La nueva versión sigue pareciendo una app SaaS moderna y no una empresa pesquera tradicional?
```

Si la respuesta es no, la evolución no va en la dirección correcta.

# 25. Resumen ejecutivo

La identidad visual de **La Pesquerapp** se basa en un símbolo minimalista de tres ondas refinadas dentro de una caja redondeada.

El logo debe funcionar principalmente en blanco y negro, con una posible variante azul secundaria. La marca debe sentirse moderna, limpia, cercana y tecnológica, alineada con una interfaz shadcn/ui y con un posicionamiento de startup SaaS.

La relación con el sector pesquero debe ser sutil, abstracta y elegante, evitando iconos literales como peces, barcos, anzuelos, pulpos o cajas.

El objetivo es construir una marca visual simple pero sólida, capaz de funcionar como icono de app, favicon, logo horizontal, marca de producto y sistema visual escalable.
